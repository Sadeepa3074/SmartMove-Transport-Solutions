Executive Reports

Five useful business reports calculated from live Oracle data through the SmartMove PL/SQL reporting package.

1. Payment & Revenue Summary

Required coursework report: paid amount, payment count, refunds, net revenue and payment-method totals.

Choose dates and run the report.

2. Driver Assignment & Schedule

Required coursework report: driver, trip, route, vehicle, departure, arrival, status and trip hours.

Run the report to load assignments.

3. Monthly Operations Summary

Required coursework report: bookings, tickets, passengers, trips run/cancelled, revenue and new passengers.

Choose month/year and run the report.

4. Most Frequently Used Routes

Required coursework report: routes ranked by bookings, tickets sold and revenue for a selected date range.

Choose dates and run the report.

5. Vehicles Due for Maintenance

Required coursework report: registration, type/model, last service, next due date, days remaining and current status.

Run the report to load maintenance due data.

Extra: Passenger Travel History

Optional coursework report. Select a real passenger instead of typing the passenger number.

Select a passenger and run the report.
